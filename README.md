📌 Project Overview

MoodFlixx is a web-based playlist generator that recommends songs based on selected moods.
It uses the Binary Search algorithm to efficiently search through a sorted dataset of songs and generate playlists quickly.

This project demonstrates the practical use of Data Structures and Algorithms (DAA) concepts in a real-world application.

- To create an interactive mood-based playlist generator

🧠 How Binary Search is Used

1. Songs are stored in a dataset sorted by:
   
   - Mood
   - BPM (beats per minute)

2. When a mood is selected:
   
   - Binary Search is applied to find matching songs quickly.
   - Instead of checking each song one by one, the dataset is divided repeatedly.

3. This reduces search time significantly.

---

⏱ Time Complexity

Binary Search Time Complexity:

- Best Case: O(1)
- Average Case: O(log n)
- Worst Case: O(log n)

This makes the playlist generation fast and efficient.
